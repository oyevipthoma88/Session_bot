# Advanced Telegram Session Bot

Generate Pyrogram User, Pyrogram Bot, and Telethon session strings.

[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/oyevipthoma88/Session_bot)

## Features
- Pyrogram User Session
- Pyrogram Bot Session
- Telethon String Session
- 2FA Support

## Deploy
1. Click Deploy button
2. Fill API_ID, API_HASH, BOT_TOKEN
3. Deploy and open bot
4. Send /start
