# 🔥 Advanced Telegram Session Bot

Best UI • All Session Types • Converter • 2FA • Saved Messages

## Features
- Pyrogram User Session
- Pyrogram Bot Session
- Telethon String Session
- Pyrogram to Telethon Converter
- 2FA Support
- Auto Saved Messages
- Premium Inline UI

## Deploy on Railway (Free)
1. Go to railway.app
2. New Project -> Deploy from GitHub
3. Select oyevipthoma88/Session_bot
4. Add Variables: API_ID, API_HASH, BOT_TOKEN
5. Deploy

## Deploy on Koyeb (Free)
1. Go to app.koyeb.com
2. Create Service -> GitHub -> oyevipthoma88/Session_bot
3. Buildpack: Python
4. Run command: python bot.py
5. Add env vars
6. Deploy

## Security
- Never share session string
- Revoke via Telegram Settings -> Devices
- Use 2FA
